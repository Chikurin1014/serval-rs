# Usage

Serval is one page: the [toolbar](toolbar.md) at its top, and a tab for each view below it:

| Tab | What it shows |
|---|---|
| [Console](console.md) | What the port receives, as a terminal; what you type is sent |
| [Data](data.md) | The data made of it, and the maps that make it |
| [Graph](graph.md) | Graphs of the data |
| [Task](task.md) | The tasks of the plugins imported (shown once a plugin is imported) |

The port stays open, and the data keep coming, whichever tab is shown.

> [!NOTE]
> Serval on the web needs the internet to open.
> To use Serval offline, use the desktop app.
